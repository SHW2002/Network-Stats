v1.5.0 降低默认后台流量，并让流量消耗在开启前即可预估。

## 更新内容

- 周期网速检测默认关闭，可在设置中手动开启；关闭时只获取响应头，保留可访问性和响应耗时监测。
- 直连和每个代理线路均可独立开关周期网速检测，全局开关关闭时不会读取任何响应体。
- 设置中的开关旁会按当前探测间隔、网站数和线路数，显示开启测速后的每小时最大流量预估。
- 主界面新增每小时预估流量指标，分别列出 Ping 可访问性请求与周期测速流量。
- 单项测速不受周期测速开关影响，仍可随时手动运行。

## 流量估算口径

- Ping 可访问性探测按每个网站、每条线路、每轮约 20 KB 估算，包含连接、请求与响应头开销。
- 周期测速按每个网站、每条线路、每轮最多读取 1 MB 响应体估算，不含协议开销，实际消耗通常更少。

## Windows 本地包

`Network-Stats.exe` 为 Windows x64 单文件便携版，配置和历史数据继续保存在原位置。
