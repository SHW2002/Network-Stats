v1.4.3 统一各平台圆角图标，并改进文档和发布流程。

## 更新内容

- 沿用原 Windows 图标的蓝底、灰色和黄色柱状图，增加圆角和至少 15% 的边距。
- Windows EXE、窗口和托盘使用包含 9 种尺寸的新图标。
- Android 自适应图标经过系统裁切后，四周仍保留约 16.3% 的留白。
- macOS 和 iOS 同步使用新图标。
- README 提供中英文切换，文末居中展示宽度为 20% 的图标。
- `dotnet publish` 自动生成 ZIP 归档；本 Release 的全部安装包由同一版本标签构建。

## 下载

| 附件 | 平台 |
| --- | --- |
| `Network-Stats.exe` | Windows x64，单文件便携版 |
| `Network-Stats-Android-arm64.apk` | Android arm64，Android 6.0 及以上 |
| `Network-Stats-macOS-arm64.zip` | Apple Silicon Mac |
| `Network-Stats-macOS-x64.zip` | Intel Mac |
| `Network-Stats-iOS-Simulator-arm64.zip` | Apple Silicon Mac 上的 Xcode Simulator |
| `Network-Stats-iOS-Simulator-x64.zip` | Intel Mac 上的 Xcode Simulator |

`SHA256SUMS.txt` 包含上述六个附件的 SHA256。

Android 版本为 1.4.3（versionCode 11），APK 使用构建环境的开发证书签名，与 v1.4.2 的开发证书不同，不能直接覆盖安装旧版；请先备份需要保留的数据。此包用于侧载，不是应用商店包。

iOS 附件仅供 Xcode Simulator 使用，不能直接安装到真实 iPhone/iPad。macOS 附件采用 ad-hoc 签名且未公证。
